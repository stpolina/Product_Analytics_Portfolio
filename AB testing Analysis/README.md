# Анализ результатов A/B-тестирования мобильного чекаута

## Цель проекта

Оценить влияние редизайна мобильного чекаута на конверсию из корзины в оформление заказа и среднюю выручку на одного участника эксперимента.

## Описание проекта

После релиза новой версии мобильного чекаута 1 апреля в исторических данных было обнаружено снижение конверсии из корзины в оформление заказа.

Для проверки гипотезы о негативном влиянии изменений интерфейса проведён анализ исторических данных и результатов A/B-тестирования.

В эксперименте сравнивались две версии интерфейса:

- **Группа A (контрольная)** - старая версия мобильного чекаута.
- **Группа B (тестовая)** - новая версия мобильного чекаута.

В качестве основной метрики использовалась конверсия из корзины в оформление заказа (Cart-to-Checkout Conversion Rate). Дополнительно анализировалась средняя выручка на одного участника эксперимента (Revenue per Participant).

В ходе исследования выполнены:
- Первичная проверка качества и структуры данных.
- Проверка уникальности пользователей и отсутствия пересечений между группами.
- Проверка корректности распределения участников между вариантами эксперимента (SRM).
- Расчёт конверсии по экспериментальным группам.
- Проверка статистической значимости различий с помощью χ²-теста.
- Расчёт 95% доверительного интервала для разницы конверсий.
- Сравнение средней выручки на участника эксперимента.
- Проверка различий в выручке с помощью перестановочного теста.
- Построение доверительного интервала для разницы средней выручки.
- Сопоставление результатов A/B-тестирования с исторической динамикой конверсии.

## Вывод исследования

По результатам анализа выявлено статистически значимое снижение обеих исследуемых метрик в тестовой группе.

**Конверсия из корзины в оформление заказа:**
- Контрольная группа A - 69,55%.
- Тестовая группа B - 48,55%.
- Разница - 20,99 процентного пункта в пользу контрольной группы.
- 95% доверительный интервал разницы - [17,55; 24,43] п.п.
- Различие статистически значимо (p < 0,001).

**Средняя выручка на участника эксперимента:**
- Контрольная группа A - 18 059,80 ₽.
- Тестовая группа B - 13 238,32 ₽.
- Разница - 4 821,48 ₽ в пользу контрольной группы.
- 95% доверительный интервал разницы - [2 635,44; 6 987,52] ₽.
- Перестановочный тест показал статистически значимое различие (p = 0,00005 при 20 000 перестановок).

Исторические данные также показывают снижение мобильной конверсии после релиза: с 68% в марте до 48% в апреле. При этом на desktop сопоставимого снижения не наблюдается.

## Использование результатов исследования

На основании результатов рекомендуется отказаться от внедрения текущей версии мобильного чекаута и сохранить предыдущую версию интерфейса.

Для дальнейшего улучшения пользовательского пути рекомендуется:

- Изучить пользовательские сессии и выявить возможные проблемы взаимодействия с элементами интерфейса (usability-test).
- Сформировать гипотезы по улучшению мобильного чекаута.
- Провести повторное A/B-тестирование после внесения изменений.

## Данные

В проекте используются два набора данных:

- 'ab_test_checkout.csv' - данные A/B-тестирования: идентификатор пользователя, назначенная экспериментальная группа, дата назначения, достигнутый этап воронки и выручка.
- 'sessions.csv' - исторические данные о пользовательских сессиях: идентификатор сессии и пользователя, дата сессии, устройство, источник трафика, страна, количество просмотренных страниц и достигнутый этап воронки.
