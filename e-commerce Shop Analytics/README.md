# Анализ данных интернет-магазина. Исследование снижения конверсии

## Цель проекта

Провести комплексный анализ пользовательского поведения интернет-магазина, исследовать динамику ключевых продуктовых метрик и выявить возможные причины снижения конверсии.

На основе результатов сформулировать продуктовую гипотезу и предложить рекомендации по её проверке.

## Описание проекта

Интернет-магазин столкнулся со снижением конверсии. Для исследования предоставлены данные за 12 месяцев, содержащие информацию о пользователях, сессиях, заказах и товарах.

В рамках проекта проведён исследовательский анализ данных (EDA), изучена динамика бизнес- и продуктовых показателей, исследовано поведение пользователей на разных этапах воронки продаж.

Основные направления исследования:

- **Предобработка данных:** проверка типов данных, пропусков, дубликатов и корректности связей между таблицами.
- **Анализ бизнес-показателей:** динамика заказов и выручки, структура заказов по статусам, распределение продаж по странам и каналам привлечения.
- **Продуктовые метрики:** DAU, MAU, Sticky Factor, ARPU, средний и медианный чек, конверсия.
- **Когортный анализ:** исследование активности пользователей после регистрации, ранней конверсии и retention.
- **Анализ воронки:** оценка переходов между этапами пользовательского пути, сравнение конверсии по устройствам и каналам привлечения.
- **Формирование гипотез:** поиск возможных причин снижения конверсии и разработка рекомендаций для дальнейшей проверки.

## Вывод исследования

В ходе анализа выявлено снижение конверсии интернет-магазина на этапе перехода из корзины к оформлению заказа, начиная с апреля 2026 года.

Наиболее заметное ухудшение наблюдается на мобильных устройствах: конверсия снизилась примерно с 68% до 49%. 

## Использование результатов исследования

Результаты анализа позволяют определить приоритетное направление для дальнейшего улучшения продукта - мобильный сценарий оформления заказа.

На основе исследования предложены следующие действия:

1. Провести технический аудит мобильного чекаута.
2. Провести A/B-тестирование вариантов мобильного оформления заказа для оценки влияния изменений на конверсию.

## Технические особенности проекта

Данные зашумлены пропусками и особенностями идентификаторов. Проведена проверка качества данных: типов столбцов, пропущенных значений, дубликатов и связности таблиц.

В ходе анализа выявлено, что 'session_id' может повторяться у разных пользователей. Для корректного объединения таблиц заказов и сессий использовался составной ключ 'user_id + session_id'.

Для ответа на вопросы исследования применялись:

- группировки и агрегации данных в различных разрезах;
- объединение таблиц по ключевым идентификаторам;
- расчёт продуктовых и бизнес-метрик;
- когортный анализ и построение retention-матрицы;
- построение и сегментация воронки продаж;
- анализ динамики показателей по месяцам;
- визуализация результатов с помощью графиков.

## Данные

В проекте использованы четыре таблицы:

- 'users' — информация о пользователях и каналах привлечения;
- 'sessions' — данные о пользовательских сессиях и достигнутых этапах воронки;
- 'orders' — информация о заказах, их суммах и статусах;
- 'products' — каталог товаров и категории.

**Масштаб данных:** 6 000 пользователей, 68 668 сессий, 7 327 заказов и 300 товаров.

Данные загружаются из открытого учебного источника Python Academy.
